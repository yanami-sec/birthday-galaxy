## Inspiration

Thanks to [this Douyin birthday demo](https://v.douyin.com/yZ8-TinPbQo/)
for the inspiration.

The project grew from an exploration of birthday greetings and these references:

- https://github.com/Seeingsprings/BirthdayWish — initial birthday greeting concept.
- https://github.com/zonezz/HappyBirthday_Yan-71b87 — an earlier particle cake experiment.
- https://github.com/KernelCrafters/Birthday-template — cake customization reference.

This repository contains the new web implementation. The original Python application,
executables and the earlier reference cake renderer are not included. The current
cake geometry, animated textures, cream, decorations, candles and particle effects
are generated procedurally by this project's code. No models, photos or textures
from the reference repositories are bundled. Acknowledgement does not change the
licenses of the referenced projects or imply their endorsement.
